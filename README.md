# CODE-SOFT-_TASKNO-1
CodSoft Task 1 – Portfolio Website

📌 Project Overview

This project is a personal Portfolio Website developed as part of my CodSoft Web Development Internship – Task 1.

The portfolio showcases my profile, skills, projects, internship experience, certifications, and contact details in a clean and responsive design.

🚀 Features

- Responsive portfolio design
- Home, About, Skills, Experience, Works, and Contact sections
- Resume download option
- LinkedIn profile link
- Project showcase
- Internship and certification details
- Mobile-friendly layout
- Smooth navigation between sections

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

├── index.html

🎯 Objective

The main objective of this project is to create a professional online portfolio that represents my web development skills, projects, and experience.
